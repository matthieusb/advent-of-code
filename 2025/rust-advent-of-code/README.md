# 2025 Advent of Code

## Pre-requisites

Install dependencies:
```bash
cargo install cargo-watch --locked
```

## Usage

To compile:
```bash
cargo build
```

To watch compile:
```bash
cargo watch -x build
```

To run tests:
```bash
cargo test
```

To run tests in watch mode:
```bash
cargo watch -x test
```
